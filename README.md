# 麵店線上點餐系統

線上/內用點餐 → 員工後台接單、列印廚房單、結帳記錄 的輕量系統。

## 先在自己電腦上測試

```bash
cd 麵店點餐系統
npm install
npm start
```

啟動後終端機會顯示三個網址：

- **客人點餐頁**：`http://localhost:3000/order.html` （線上預購模式）
- **內用點餐頁**：`http://localhost:3000/order.html?table=A3` （網址後面加 `?table=桌號`，之後幫每桌做一張對應桌號的QR code貼在桌上就行）
- **員工後台**：`http://localhost:3000/staff.html` （預設密碼 `admin123`，正式使用前一定要改，見下方「修改密碼」）

## 手機測試（跟真實使用情境一樣）

電腦、手機要連**同一個WiFi**，用電腦的區域網路IP取代 `localhost`，例如 `http://192.168.1.5:3000/order.html?table=A3`，用手機瀏覽器打開就能像客人一樣點餐、送出，然後回電腦上的員工後台看訂單有沒有跳出來、按列印試印。

## 修改員工密碼

不要用預設密碼上線。啟動前設定環境變數：

```bash
# Windows PowerShell
$env:STAFF_PASSWORD = "換成你自己的密碼"
npm start
```

## 商品管理

第一次啟動會自動塞幾筆範例商品（乾拌麵、滷豆干、雞腳等），到員工後台「商品管理」分頁可以直接改名稱/價格/分類，或新增/下架，不用改程式碼。

## 印表機

1. 把熱感應印表機接上要當「員工後台」那台電腦/平板，依廠商說明安裝好Windows/Android印表機驅動（多數熱感機都支援）
2. 員工後台每張訂單卡片按「列印廚房單」，會開一個新分頁自動彈出列印視窗，選擇你的熱感印表機即可
3. 紙寬預設抓78mm，如果你的出單機是58mm窄版，把 `public/print.html` 裡 `width: 78mm` 改成 `58mm`

## 之後要上雲端（讓客人在家也能預購）

現在用的是本機檔案資料庫（SQLite），跑在你電腦上。要讓外面的人連得到，需要：

1. **申請一個主機服務**：推薦 [Render.com](https://render.com)（有免費方案可以先試）
2. **換成雲端資料庫**：Render免費方案的硬碟不是永久保存的（重啟可能會把訂單資料洗掉），正式上線建議資料庫換成 [Supabase](https://supabase.com)（免費方案的Postgres資料庫，資料不會不見）或 [Turso](https://turso.tech)（相容SQLite，免費方案也夠用）
3. 這一步需要你自己申請帳號、跟我要一起把連線設定接上，資料表結構已經寫好了可以直接沿用，屆時再麻煩你回來找我接手這段

## 目前限制（先講清楚，之後有需要再加）

- 員工登入是簡易共用密碼，沒有多帳號權限管理
- 沒有串接電子發票（統一發票），量做大之後可能需要
- 印表機是「按按鈕手動列印」，不是訂單一進來自動印
- 沒有線上金流，訂單是「先下單、現場/取貨時付款」
